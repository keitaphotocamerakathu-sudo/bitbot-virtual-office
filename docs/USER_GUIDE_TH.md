# คู่มือ Bitbot v14

เปิดเว็บแล้วเลือก **ทดลองเทรด** เข้าสู่ระบบด้วยบัญชีเดิม หากต้องการเปลี่ยนทุน ให้หยุด Paper และปิดสถานะจำลองก่อน แล้วบันทึกที่ **Risk Control** จากนั้นกด **เริ่มทดลองบอท** จะรันบนเซิร์ฟเวอร์แม้ปิดคอม ทุกชุดใช้เงินจำลองแยกกัน เงินทุนไม่ได้ถูกแบ่งหกส่วนจากกระเป๋าจริง การเปิดเว็บหรือรีโหลดไม่เริ่มซื้อขายเอง

**Virtual Office** แสดงฝ่าย CEO, CIO, Market, News, Quant, Portfolio, Risk, Execution, Audit และ Learning กดตัวละครหรือปุ่ม Worker เพื่ออ่านผลคำนวณ **วิเคราะห์รอบนี้** สร้างบันทึกวิเคราะห์โดยไม่ส่งคำสั่ง ส่วน **เล่นบันทึกงาน** แสดงภาพย้อนจากงานที่บันทึกไว้และยืดเวลาเพื่อให้อ่านทัน ข้อความใน AI Conversations เป็นการส่งต่องานจากผลคำนวณจริง ระบบนี้ยังไม่มีโมเดลภาษาหรือบอทคุยอิสระ

**Market Scanner** แสดงคะแนนและข้อจำกัดของเหรียญคู่เงินบาท ไม่ได้จำกัด BTC แต่จะวิเคราะห์แท่งละเอียดเป็นกลุ่มหมุนเวียนตามสภาพคล่องและเหรียญที่ถือ **News** แสดงแหล่งข่าวและความพร้อม ข่าวที่อ่านเนื้อหาไม่ได้จะแจ้งว่าใช้เพียงหัวข้อ ข่าวเพียงอย่างเดียวไม่ทำให้ซื้อ

**Daily Profit** เลือกรายวัน สัปดาห์ เดือน หรือปี และกดอัปเดตรายงาน กำไรที่ขายแล้วคือผลสุทธิหลังค่าธรรมเนียม ส่วนกำไรของเหรียญที่ยังถือเป็นประมาณการจากราคา Bid และต้นทุนขาย เงินฝาก/ถอนหรือเหรียญที่ซื้อเองไม่ถูกสร้างเป็นกำไรบอท รายการก่อนเริ่มเก็บ Ledger อาจไม่มีวันที่ครบ ระบบจะแจ้งขอบเขตแทนการสร้างประวัติขึ้นใหม่ ส่งออก CSV/Excel ได้

**System Health** แสดงสถานะ Cloud คิวงาน และความคืบหน้า 14 วัน/20 รอบ เกณฑ์นี้ใช้กันกลยุทธ์ที่ยังไม่มีหลักฐานเข้าเงินจริง การครบจำนวนยังต้องมีผลวิจัยผ่านและเจ้าของยืนยัน LIVE ไม่ได้รับประกันกำไรทุกวัน หาก Paper หยุด ข้อมูลเก่า หรือขาดช่วงเกินห้านาที จะไม่ถือว่าเป็นการทดลองต่อเนื่องครบเวลา

ปุ่ม **พักซื้อใหม่** ให้ระบบเฝ้าขายสถานะเดิมต่อ ปุ่ม **หยุดบอท** หยุดการเฝ้าสถานะด้วยและเก็บเหรียญไว้ การเปิดใหม่อ่านสถานะเดิมจากเซิร์ฟเวอร์และตรวจคำสั่งค้างก่อนตัดสินใจ ขณะหยุดจะไม่ขายตามเวลาเอง ปุ่ม **ปิดสถานะของบอท** อยู่ใน Live Trading ต้องพิมพ์ยืนยัน ขายเฉพาะจำนวนที่บอทถือและอาจติดข้อจำกัดสภาพคล่อง/วงเงิน/ขั้นต่ำตลาด

หากปิดเว็บหรือออกจากระบบ บอทที่เปิดบน Cloud ยังทำงานจนกดหยุด การปิดคอมไม่ได้เปลี่ยนปุ่มหยุด การติดตามเป็นรอบนาทีและคำสั่ง Limit อาจขายไม่ทันจุด Stop Loss หรือไม่จับคู่ จึงไม่มีการรับประกันเงินต้นหรือกำไรรายวัน

การอัปเกรดครั้งนี้คงสถานะหยุดของทั้งเงินจริงและ Paper เดิมไว้ ให้ตรวจหน้า System Health ก่อนเริ่มทดลองด้วยตนเอง
