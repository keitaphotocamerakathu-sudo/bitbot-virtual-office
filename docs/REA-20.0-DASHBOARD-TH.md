# REA 20.0 — พอร์ตและออฟฟิศในหน้าเดียว

## จุดที่แก้ไข

หน้าเดิมอ่านสถานะจาก executor รุ่นเดิม ส่วน REA Live ใช้สมุดบัญชีใหม่ ทำให้ผู้ใช้เปิดบอทจริงแล้วแต่กลับไปดูข้อมูลคนละชุด Animation เดิมยังอยู่ในหน้าเดิมแต่ไม่ได้เชื่อมหน้า REA ใหม่ แบบฟอร์มเชื่อมต่อยังแสดงเต็มหน้าตอนบอทเปิดแล้ว และหลังบันทึก Key ไม่แสดง Wallet ที่ API ตอบกลับทันที

- `index.html` เปิด `rea.html#live` เป็นหน้าหลัก `bitbot-login.html` เปิด login ใน REA โดยใช้บัญชีเดิมและการยืนยันจาก Server
- Wallet, มูลค่าพอร์ตที่บอทดูแล, กำไรวันนี้, ความเสี่ยง, สถานะที่ถือ และกิจกรรมซื้อขายจริงอยู่ก่อนส่วนตั้งค่า
- แบบเปิด Live ซ่อนหลังจัดสรรทุนแล้ว แบบ Key ย่อและไม่ให้ส่งซ้ำเมื่อมีพอร์ต Live ผูก Key อยู่
- หลังบันทึก Key แสดงผลตรวจ Wallet จากคำตอบจริงทันที พร้อมระบุว่ารอ Backend ตรวจรอบถัดไป ไม่ใช้คำตอบนี้ปลด readiness หรือเปิด Live เอง
- API, รอบวิเคราะห์ และตัวเฝ้าความเสี่ยงแสดงเวลาแยกกัน ข้อมูลเก่าหรืออ่านไม่สำเร็จแสดงชัดเจน
- Scanner, สถานะ, ประวัติ, กำไร และทีมงาน ใช้ตัวเลือกเงินจริง/Paper ชุดเดียว ไม่แสดงพอร์ตจำลองเป็นเงินจริง
- แสดงราคาจับคู่เฉลี่ยจาก receipt, ราคา Bid ล่าสุดเฉพาะ quote ที่ยังสด และกำไรประมาณหลังสำรองค่าขาย 0.25% เมื่อไม่มีราคาสดแสดงรอราคา
- คืน Virtual Office บนหน้าหลักและหน้าออฟฟิศ 7 บทบาท พร้อมเลื่อน ซูม ดูทั้งห้อง ปรับความเร็ว และพักภาพ
- Animation อ่านผลที่บันทึกไว้เท่านั้น การเดิน/การสรุปเป็นภาพแสดงงาน ไม่ถือเป็นข้อความที่เอเจนต์ส่งถึงกันจริง และไม่มีสิทธิ์เรียกคำสั่งเทรด เมื่อข้อมูล Backend ไม่สดจะระบุบนจอ
- แสดง LLM แยกจากกฎซื้อขาย รวมเวลาผลสรุปและสถานะแคช
- อ่านทั้ง Live และ Paper ทุก 15 วินาที ไม่หยุดการอัปเดตเงินจริงเมื่อไปดูหน้าทีมงาน ออกจากระบบล้างข้อมูลบัญชีและบันทึกในออฟฟิศทันที

## ขอบเขต Backend

เพิ่มเฉพาะข้อมูลแสดงผลใน snapshot: quote ของเหรียญที่บอทถือ, ปัจจัยคะแนน/อินดิเคเตอร์ที่คำนวณอยู่แล้ว, เวลาและจำนวนตลาด/ข่าวที่ตรวจ ไม่เพิ่มการเรียก API ซื้อขาย ไม่เปลี่ยนกลยุทธ์ วงเงิน การอนุมัติ lease หรือการกระทบยอด และไม่รีเซ็ตพอร์ตที่กำลังทำงาน

`assets/rea-view-model.mjs` และ office renderer เป็นโมดูลแสดงผล ไม่มี HTTP ซื้อขาย ไม่มี credentials หรือการแก้ risk state

## ตรวจสอบ

เพิ่มการตรวจแหล่งข้อมูลเงินจริง/Paper การแสดง fill และ quote ที่สด การแสดงข้อมูลเก่า การล้างข้อมูลเมื่อสลับบัญชี การนำทางจากหน้าเดิม ผลหลังบันทึก Key และ Animation/มือถือ คงการทดสอบ execution และการป้องกันคำสั่งซ้ำเดิม

ประวัติระบบเดิมและเครื่องมือกู้บัญชีคงอยู่ที่ `legacy.html` ระบบ Live ที่ Server ยังเป็นตัวควบคุมสิทธิ์และความเสี่ยง ไม่ขึ้นกับหน้าเว็บหรือ Animation
