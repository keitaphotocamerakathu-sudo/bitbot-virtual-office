# REA 30.0 — ยอดเงินบาทและเศษเงินจากการขาย

แก้เงินรับจาก SELL ให้ตัดเศษสุทธิลงเหลือสองตำแหน่งต่อผลจับคู่ด้วยเลขฐานสิบ แทนการปัดใกล้สุด เช่น เงินรับ 10.079996 บาทต้องบันทึก 10.07 บาท การใช้ 10.08 บาทสะสมหลายครั้งทำให้สมุดบัญชีสูงกว่าเงินจริง และตัวตรวจ Wallet ปฏิเสธการทำงาน

กฎอ้างอิง [Bitkub FAQ ข้อ 22](https://support.bitkub.com/en/solutions/articles?id=151000199019) และ [เอกสาร Order Info](https://github.com/bitkub/bitkub-official-api-docs/blob/master/rest-v3.md) ค่าธรรมเนียมสุทธิหักเครดิตตามผลจับคู่ที่ Exchange รายงาน ไม่สมมติว่าค่าธรรมเนียมเป็นศูนย์ทุกบัญชี

หน้า Live แสดง Available ของ THB จาก Bitkub โดยตรง พร้อม Reserved เวลาอ่าน Wallet เงินสดของบอท และส่วนต่าง รวมเงินที่ถูกจองก่อนเทียบกับสมุดบัญชี ยอดพอร์ตที่รวมเหรียญแสดงแยก ข้อมูล Wallet ที่เกิน 30 วินาทีจะไม่แสดงเป็นยอดพร้อมใช้ปัจจุบัน

ตัวตรวจ Backend เปรียบเทียบเป็นสตางค์ โดยไม่ขยายค่าผ่อนปรนเพื่อซ่อนส่วนต่างที่ยังอธิบายไม่ได้ เงินบาทนอกทุนบอทไม่เพิ่มทุนที่อนุมัติ และยอดเหรียญภายนอกไม่ถูกนำมาสร้างรายการจับคู่ของบอท

## การแก้ข้อมูลเก่า

ไฟล์ `supabase/rea_thb_settlement_v13.sql` เพิ่มเครื่องมือบำรุงรักษา `rea.repair_thb_settlement_v30(uuid)` ที่ผู้ใช้เว็บและ service_role ไม่มีสิทธิ์เรียก ไม่เพิ่มเส้นทางส่งคำสั่งซื้อขาย

เครื่องมือตรวจผลจับคู่ครบและตรงกับคลังหลักฐาน ไม่อนุญาตเมื่อมีคำสั่งที่ยังไม่ทราบผล ตรวจการคำนวณยอดเดิมได้จากทุนและรายการทั้งหมด และยอมแก้เฉพาะเมื่อยอดใหม่จากการตัดเศษตรงกับ Wallet จริงที่ยังสดทุกสตางค์ การฝากถอนที่อธิบายไม่ได้ทำให้การแก้ถูกปฏิเสธ

การแก้เป็น Transaction เดียว: เก็บ State และบทเรียนเดิมพร้อมส่วนต่างรายผลจับคู่ใน Audit, แก้เงินสด ผลสุทธิ รายการปิด บทเรียน กำไรขาดทุนแต่ละวัน และ Equity ย้อนหลังตามวันที่เกิดรายการ ไม่โยนส่วนต่างทั้งหมดเป็นการขาดทุนของวันที่แก้ ป้องกัน Worker เก่าเขียนทับด้วยการเปลี่ยน Revision และยกเลิก Lease เดิม ทำซ้ำจะไม่ปรับเงินซ้ำ

สถานะ Pause, Emergency Stop, ทุนที่อนุมัติ จำนวนช่อง และระดับ Stop/Target ของเงินจริงคงตามคำสั่งเจ้าของเดิม หลังแก้ Backend ต้องอ่านข้อมูลและตรวจความเสี่ยงรอบใหม่

## การตรวจสอบ

- ทดสอบการตัดเศษ ค่าธรรมเนียมกับเครดิต Partial Fill, Retry, Restart และการเทียบ Wallet ที่มีเงินจองหรือเงินนอกบอท
- ทดสอบฐานข้อมูลด้วยเจ้าของจำลองและ Rollback: Wallet เก่า การถอนที่อธิบายไม่ได้ คำสั่ง UNKNOWN หลักฐานไม่ครบ การปรับรายวัน/Curve/บทเรียน การป้องกัน Worker เก่า และสิทธิ์เรียกเครื่องมือ
- ทดสอบหน้าเว็บกับข้อมูลจำลอง: Available แยก Reserved, แสดงส่วนต่าง, วันเวลาเก่า, ออกจากระบบล้างข้อมูล และหน้าจอมือถือ

คำสั่งซื้อขายจริงไม่ได้เป็นส่วนหนึ่งของการทดสอบหรือการบำรุงรักษานี้
