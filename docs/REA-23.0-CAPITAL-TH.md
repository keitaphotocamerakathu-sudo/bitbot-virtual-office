# REA 23.0 — คำแนะนำเงินทุนและขนาดไม้

เพิ่มผู้ช่วยวางแผนเงินทุนบนหน้าเงินจริง ใช้กฎตัวเลขบน Backend ไม่เรียก Codex หรือ LLM เพิ่ม และไม่มีสิทธิ์ฝากเงิน เปลี่ยนงบ แก้ Risk Limit หรือส่งคำสั่ง

## สิ่งที่บอทบอก

- ตอนนี้ยังไม่ต้องเติม เพราะมีเงินพอ เต็ม 2 ช่อง รอคำสั่งเดิม หรือยังไม่มีสัญญาณเหรียญใหม่ที่ผ่าน
- รอประเมิน เมื่อ Wallet/ราคาไม่สด กระทบยอดไม่ได้ ระบบผิดปกติ หรือถูกพัก/ล็อกความเสี่ยง
- ขนาดไม้ใหม่ต่อเหรียญ วงเงินเสี่ยงที่เหลือ ระยะ Stop และขาดทุนตามแบบจำลองที่รวมต้นทุน
- เงินที่ใช้ได้สำหรับบอท วงเงินสูงสุดต่อเหรียญ และต้นทุนไม้ที่ถืออยู่
- ถ้ามีสัญญาณผ่านแต่เงินบอทไม่ถึงไม้ขั้นต่ำ: แสดงช่องว่างขั้นต่ำ รวมเงินเผื่อ และแยกเงินที่ต้องเติมเข้า Wallet ออกจากวงเงินบอทที่ต้องขออนุมัติเพิ่ม

## กฎการประเมิน

ใช้ `riskSizeREA`, `riskProjection`, `liveLimits` และ Wallet ที่ตรวจสอบจริงชุดเดียวกับ Execution Engine ขนาดที่เปิดได้เป็นค่าต่ำสุดของวงเงินตาม Stop/ค่าธรรมเนียมไปกลับ/Slippage, เงินที่ยังไม่จอง, เงิน Wallet ที่ใช้ได้, เพดานต่อเหรียญ และ Exposure ที่เหลือ ไม้ที่ต่ำกว่าขั้นต่ำของตลาดแสดงว่าเปิดไม่ได้ ไม่ปัดขึ้นให้เกินความเสี่ยง

เงินสดขั้นต่ำเพื่อรองรับคำสั่งใช้ `ceilSatang(ceilSatang(minQuote) × (1 + buyFee) + 0.10)` ตามเงินเผื่อของเครื่องยนต์เดิม สำหรับขั้นต่ำ 10 บาทได้ 10.13 บาท ค่าธรรมเนียมเป็นสมมติฐานของระบบปัจจุบัน 0.25% ต่อด้านสำหรับคู่ THB, Slippage เผื่อ 0.20% และไม่ใช่หลักประกันขาดทุนสูงสุดเมื่อราคากระโดด

ตัวอย่างสังเคราะห์: บอทมีเงินสด 5 บาท มีสถานะเดิมหนึ่งรายการ มีสัญญาณใหม่ที่ผ่านและยังมีวงเงินเสี่ยงพอสำหรับขั้นต่ำ 10 บาท ต้องเพิ่มเงินให้บอทใช้ 5.13 บาท ถ้า Wallet มี 9 บาทอยู่แล้ว ช่องว่างฝากเงินภายนอกมีเพียง 1.13 บาท แต่อีก 5.13 บาทยังต้องผ่านการอนุมัติเพิ่มวงเงินบอท ข้อมูลนี้เป็นแผนตาม Snapshot ต้องตรวจราคากับกฎใหม่ก่อนใช้เงินจริง

ไม่เสนอเติมเพิ่มเพื่อไล่คืนขาดทุนในวันที่ติดลบ ไม่เพิ่มงบเกินเพดานโหมด 100/10,000 บาท ไม่ข้าม Daily Lock ไม่แนะนำซื้อเพิ่มในเหรียญที่ถือ และไม่เพิ่มจำนวนสถานะสูงสุด ผลกำไรหรือเงินนอกบอทไม่เพิ่มวงเงินที่อนุมัติเอง ข้อเสนอเติมเงินเป็นเงื่อนไขความพร้อมของระบบ ไม่ได้ประเมินรายได้ ภาระหนี้ หรือเงินสำรองส่วนตัวของเจ้าของ

## การทำงานและหลักฐาน

Strategy ประเมินสัญญาณทุกนาที Independent Risk Worker ทบทวนเงินและล็อกจากผลเดิม โดยไม่อ่านแท่งเทียน ข่าว หรือ AI เพิ่ม ราคาสัญญาณเกิน 30 วินาทีต้องรอข้อมูลใหม่ ตัวเฝ้า Stop Loss ยังทำงานแยกตามเดิม

ผลปัจจุบันเก็บที่ `latest.capitalAdvice` ในบัญชี Live และแนบใน `latest.team.capitalAdvice` รอบ Strategy เพื่อให้ Trigger เดิมเก็บย้อนหลังใน `rea.review_cycles` ผลสรุปการเติมเงินปรากฏในงานของ Portfolio Auditor ในออฟฟิศด้วย ไม่มี Schema หรือสิทธิ์อ่านข้อมูลใหม่

หน้าเว็บปฏิเสธคำแนะนำที่เก่ากว่า 45 วินาทีหรือ Timestamp ผิดปกติ และล้างข้อมูลเมื่อออกจากระบบ ไม่มีปุ่มฝากเงิน/เพิ่มวงเงินอัตโนมัติ

## การตรวจสอบ

- ทดสอบขนาดไม้เทียบกับ Order Planner จริงทั้ง STANDARD และ OWNER_LIMITED_LIVE, ลดทุนแล้วขนาดไม้ลด, ไม่ใช้เงินนอกงบเพื่อเพิ่มไม้เอง
- ทดสอบช่องเต็ม คำสั่งไม่ทราบผล เงินจอง ข้อมูลเก่า Wallet ผิดรูปแบบ Daily Lock เงินขั้นต่ำ และวันติดลบ
- ทดสอบแยกยอดฝากจากงบบอท การบันทึกหลักฐานรอบ Strategy และยกเลิกข้อเสนอเก่าเมื่อ Risk Worker พบล็อกหรือ Private API ผิดพลาด
- Browser ตรวจข้อความยอดเงิน การหมดอายุ การออกจากระบบ ข้อความแปลกปลอม และมือถือ
- ทดสอบโดยไม่ส่งคำสั่งซื้อขายเงินจริง การใช้งาน Live เดิมยังอยู่ภายใต้งบและการอนุมัติเดิม
