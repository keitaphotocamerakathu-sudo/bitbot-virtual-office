# Bitbot Virtual Trading Office v4

[**เปิดเว็บ Bitbot Virtual Trading Office**](https://keitaphotocamerakathu-sudo.github.io/bitbot-virtual-office/)

> **PAPER TRADING ONLY:** เว็บไซต์นี้ทดลองด้วยข้อมูลราคาสังเคราะห์และกฎการวิเคราะห์ ไม่เชื่อมบัญชีซื้อขาย Bitkub ไม่ใช้เงินจริง และไม่เปิด API ส่งคำสั่งซื้อขาย

## ฟังก์ชัน

- ออฟฟิศเสมือน 2.5D พร้อมอวตาร 5 ตัว (Coordinator, Trend, Risk, Strategy, Execution)
- จำลองราคา BTC/THB / BUY / SELL / HOLD, Stop Loss และ Take Profit
- เปรียบเทียบตัวกรองตลาด 3 แบบ: ปิดกรอง, สมดุล, เข้มงวด
- เลือกสถานการณ์ตลาดหรืออัปโหลด CSV OHLCV เพื่อทดสอบ
- **Trading Memory v4:** จดบันทึกรอบทดสอบ สัญญาณทุกแท่งเทียน การซื้อ–ขาย ค่าธรรมเนียม และข้อสังเกตลง IndexedDB ในเบราว์เซอร์
- ส่งออกและนำเข้าประวัติเป็น JSON; เสนอทำ A/B Test ชุดข้อมูลใหม่จากบทเรียนที่บันทึก
- ไม่มีการฝึกโมเดล Machine Learning ใหม่และ **ไม่เปลี่ยนกลยุทธ์อัตโนมัติ**

## วิธีทดลอง

1. เปิดเว็บไซต์แล้วเลื่อนไปส่วน **Trading Simulator** และเลือกตลาด/ตัวกรอง
2. กด **เริ่มจำลอง**, **ทีละแท่ง** หรือ **โชว์ BUY → SELL ทันที**
3. เลื่อนไปส่วน **Trading Memory** เพื่อตรวจรายการบันทึกย้อนหลัง
4. กด **สำรองทุกอย่าง JSON** เป็นประจำ และใช้ **นำเข้าประวัติ** หากต้องการโหลดไฟล์บทเรียนเดิม
5. กด **ใช้บทเรียนออกแบบ A/B ใหม่** เมื่อมีผลทดสอบหลายชุดข้อมูลเพียงพอ

## การเก็บประวัติ

- ข้อมูลใน IndexedDB อยู่ **เฉพาะเครื่องและเบราว์เซอร์** ของผู้เข้าชม ไม่เก็บขึ้น GitHub/Supabase โดยอัตโนมัติ
- ใช้เบราว์เซอร์หรืออุปกรณ์อื่นแล้วจะไม่เห็นประวัติเดิม จนกว่านำเข้าไฟล์ JSON ที่สำรองไว้
- การล้างข้อมูลเว็บไซต์หรือใช้โหมดไม่ระบุตัวตนอาจทำให้ประวัติหาย
- การบันทึกฐานข้อมูล SQLite แบบถาวรอยู่ในแพ็กเกจทดสอบแยกบนเครื่อง ไม่ใช่ GitHub Pages

## ข้อมูลทดสอบ v4

ชุด Stress Lab ออฟไลน์: 59 รอบ, 26,676 การตัดสินใจ, 169 คำสั่งจำลอง, 37 บทเรียนจากข้อมูลสังเคราะห์ ตัวเลขเหล่านี้เป็น **ผลทดสอบแยก** ไม่ได้ใส่อัตโนมัติในเบราว์เซอร์ที่เพิ่งเปิดเว็บไซต์

การทดสอบออฟไลน์ผ่าน Python QA 6 กรณีและตรวจไวยากรณ์ JavaScript แล้ว แต่การบันทึก IndexedDB ผ่านเบราว์เซอร์จริงบน GitHub Pages จำเป็นต้องทดสอบหลังเผยแพร่

## การเผยแพร่

ไฟล์ `index.html` เป็นเว็บไซต์หลัก GitHub Actions อยู่ที่ `.github/workflows/deploy-pages.yml`. สำรอง v3 อยู่ในสาขา `backup-v3-before-learning-v4`.

**คำเตือน:** ผลทดสอบย้อนหลังหรือสถานการณ์สังเคราะห์ไม่ใช่การรับประกันกำไรหรือการพิสูจน์ว่า AI เรียนรู้ตลาดได้แล้ว
