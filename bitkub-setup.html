เชื่อมบัญชี Bitkub

ตั้งค่า API บนเว็บไซต์ได้โดยตรง คีย์เข้ารหัสเก็บใน Supabase Vault แยกตามบัญชี · ไม่มีการส่งคำสั่งซื้อขายในหน้าตั้งค่านี้

🔒 โปรดสร้าง API Key โดยไม่เปิดสิทธิ์ถอนเงิน (Withdraw) และจำกัด IP ที่อนุญาตหาก Bitkub รองรับการตั้งค่าตามรูปแบบการเชื่อมต่อของคุณ ห้ามใส่ API Key ใน GitHub หรือส่งให้ใครผ่านแชต
1เข้าสู่ระบบ Bitbot

เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน Bitbot ที่มีอยู่ ไม่ต้องขอลิงก์ใหม่ทุกครั้ง

🔑 เข้าสู่ระบบ Bitbot ครั้งเดียว

หากเคยล็อกอินในเบราว์เซอร์นี้แล้ว ระบบจะกลับมาหน้า Setup อัตโนมัติ ไม่ต้องกรอกรหัสใหม่

ตัวเลือกอื่น: เข้าสู่ระบบในหน้านี้

บัญชีที่ลงทะเบียนและยืนยันอีเมลไว้แล้ว เข้าระบบด้วยรหัสผ่านได้ทันที ไม่ต้องขอลิงก์อีเมล

🔑 ลืมรหัสผ่าน / ต้องการขอลิงก์เข้าระบบทางอีเมล

ลิงก์ตั้งรหัสผ่านใหม่จะส่งไปที่อีเมลที่ลงทะเบียนไว้ และอาจติดข้อจำกัดโควตาอีเมลของ Supabase

ใช้เข้าสู่ระบบครั้งต่อไปโดยไม่ต้องขอลิงก์อีเมลบ่อย ๆ อย่าใช้รหัสผ่านเดียวกับ Bitkub

กำลังตรวจสอบสถานะการเข้าสู่ระบบ...
2บันทึก API Key / Secret อย่างปลอดภัย

สร้าง API Key จาก หน้าจัดการ API ของ Bitkub ให้มีสิทธิ์อ่าน Wallet เพื่อตรวจสอบก่อนบันทึก

ยังไม่ได้ตรวจสอบข้อมูลบัญชี
3ตั้งวงเงินความเสี่ยง

เป็นขีดจำกัดต่อบัญชีที่บันทึกฝั่งเซิร์ฟเวอร์ แต่ ยังไม่ใช่การเปิดเทรดเงินจริง

🔒 เทรดเงินจริงยังปิดอยู่
สถานะตรวจสอบ: รอเข้าสู่ระบบ • จะไม่ส่งคำสั่งเงินจริงจากหน้า Setup
!เปิด–ปิดการส่งคำสั่งเงินจริงด้วยตนเอง

เฉพาะ LIMIT BTC/THB แบบกดยืนยันทีละคำสั่ง ไม่ใช่ AI เทรดอัตโนมัติ ระบบจะเช็กสิทธิ์ Wallet และวงเงินอีกครั้งทุกครั้งที่ส่งคำสั่ง

เพดานเริ่มต้นฝั่งเซิร์ฟเวอร์: สูงสุด 100 บาทต่อคำสั่ง • ซื้อ 300 บาท/วัน • ขายมูลค่า 1,000 บาท/วัน

4สถานะและการจัดการความปลอดภัย

คุณสามารถลบ API Key ที่บันทึกใน Vault ออกจากระบบได้ทุกเมื่อ โดยไม่ต้องลบบัญชี Bitbot
