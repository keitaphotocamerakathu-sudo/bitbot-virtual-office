3. สถานะระบบและข้อจำกัด

กำลังตรวจสอบ Backend...
การเชื่อมต่อราคาไม่ต้องมีบัญชี Bitkub แต่การอ่านยอดเงินและซื้อขายจริงต้องมี Bitkub API Key / Secret, สิทธิ์ผู้ดูแล, ขีดจำกัดวงเงินที่ตั้งฝั่งเซิร์ฟเวอร์ และการเปิด Kill Switch เท่านั้น ไม่มีการถอนเงินผ่านระบบนี้
วิธีเปิดคำสั่งเงินจริงอย่างปลอดภัย

ตั้ง API Key/Secret และวงเงินที่หน้า ⚙ ตั้งค่า Bitkub ได้โดยตรง แต่การอนุญาตออร์เดอร์เงินจริงยังต้องมีการอนุมัติ UID ในระบบฝั่งเซิร์ฟเวอร์ และเปิด Kill Switch / Global Caps ด้วยผู้ดูแลเท่านั้น ห้ามนำ Secret ไปใส่ GitHub
